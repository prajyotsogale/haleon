# Haleon

Haleon is an enterprise-grade digital banking platform built using Java and Spring Boot. It is designed to simulate a real-world banking system with secure authentication, role-based access control, account management, fund transfers, transaction history, beneficiary management, audit logging, and modern backend development practices.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- PostgreSQL
- Flyway
- JWT Authentication
- Maven
- Docker
- Swagger/OpenAPI
- JUnit 5 & Mockito
- Testcontainers
- GitHub Actions (CI/CD)

## Planned Features

- User Registration & Login
- JWT Authentication & Refresh Tokens
- Role-Based Access Control (RBAC)
- Savings & Current Accounts
- Secure Money Transfers
- Beneficiary Management
- Transaction History
- Account Statements
- Admin Dashboard
- Audit Logging
- Login History
- Email Notifications
- Pagination, Filtering & Sorting
- Dockerized Deployment
- Comprehensive Unit & Integration Testing
